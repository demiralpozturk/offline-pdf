# Changelog

## 1.0.0 — 2026-11-27

First public release.

- 15 tools: merge, split, extract, delete, reorder, rotate, compress, PDF info, images → PDF, PDF → images, watermark, page numbers, edit/strip metadata, protect (AES-256), unlock.
- Drag & drop, page thumbnails, batch processing, password prompts for protected files.
- English and Turkish interface, light and dark themes.
- `offlinepdf-cli` command line with every tool.
- `--selftest` mode to verify a build headlessly.
